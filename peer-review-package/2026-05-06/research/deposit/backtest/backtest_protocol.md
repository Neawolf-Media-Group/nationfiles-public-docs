## Backtest protocol (audit-ready, dated)

**As of (UTC):** 2026-05-05  
**Scope:** This protocol defines *how* backtests are selected, computed, and statistically evaluated for the NationFiles Stability Index (NFSI). It is designed to be executable against deposited artefacts and/or DB extracts without manual intervention.

### 1) Objectives and non-objectives

- **O1 (descriptive validity):** quantify whether NFSI shows systematic, directional reaction around high-impact days/events (event-study framing).
- **O2 (robustness):** quantify sensitivity of outcomes to connector weight perturbations and missingness policy variants where applicable.
- **O3 (crash-mode evaluation):** evaluate crash-mode gating as a classifier given *explicit* ground-truth labels (if available).

Non-objectives (must not be claimed):

- **NO1 (forecast skill claims):** unless forecast archives exist with issue-time predictions, no predictive skill claim is made. Persistence-baseline evaluation is reported separately from any model claims.

  - Generated by: `research/deposit/recompute/named_events_from_db.php`

### 3) Hypotheses (pre-registered style)

Let $y_{c,t}$ be published NFSI for country $c$ on day $t$. Let an event day be $t_0$.

- **H1 (level shift):** the post-window mean differs from pre-window mean:  
  $ \Delta\mu = \mu_{\text{post}} - \mu_{\text{pre}} \ne 0 $
- **H2 (extreme reaction):** the event-day absolute change $|\Delta y_{c,t_0}| = |y_{c,t_0}-y_{c,t_0-1}|$ is higher than baseline absolute daily changes for the same country.
- **H3 (crash-mode discriminative):** with an explicit ground-truth crisis label $z_{c,t}\in\{0,1\}$, crash-mode predicate has AUC > 0.5.

### 4) Event selection rules (deterministic)

#### 4.1 Data-driven (top-$k$ absolute deltas)

Selection is deterministic given the DB snapshot or exported table:

- Universe: `nfsi_country` rows with `date_ymd >= 2026-02-14` (implementation constant `NFSI_DATA_VALID_FROM`).
- Score: $|\Delta y_{c,t}| = |y_{c,t} - y_{c,t-1}|$.
- Select top $k$ rows by $|\Delta y|$, with **unique iso2** constraint (one event per country).
- Window length: $W=7$ days pre and $W=7$ days post.

Outputs are recorded in `backtest_events.csv.txt` with pre/post summaries (mean, sd, min/max).

#### 4.2 Named events (sources with explicit event metadata)

Selection is deterministic given event-source tables:

- Sources: ACLED, UCDP GED, GDACS, USGS, `CountryNewsRiskLevel`, etc.
- Severity proxy: `severity_value` as defined per source table.
- Combined score: $|\Delta y_{c,t}| + 0.1 \cdot \text{severity_value}$.
- Select top $k$ unique $(iso2, source)$.
- Post-window: $W=7$ days.

Outputs are recorded in `named_events_backtest.csv.txt`.

### 5) Metrics (what we compute)

Per event record (data-driven):

- **Event-day delta:** $\Delta y_{c,t_0}$
- **Pre mean / sd:** $\mu_{\text{pre}}, \sigma_{\text{pre}}$
- **Post min/max:** $\min_{\text{post}}, \max_{\text{post}}$
- **z-style deviation vs pre:** $ z = \frac{y_{c,t_0}-\mu_{\text{pre}}}{\sigma_{\text{pre}}+\epsilon} $ with $\epsilon=10^{-6}$
- **Effect size (Cohen’s d, windowed):**  
  $ d = \frac{\mu_{\text{post}}-\mu_{\text{pre}}}{s_p} $ with pooled $s_p$ (Welch variant allowed)

Across events (aggregate):

- distribution of $\Delta y$, distribution of $z$
- fraction of events with $|z| \ge 2$
- median $|\Delta y|$

### 6) Significance tests (robust, dependency-light)

#### 6.1 Summary-based test (executable with the deposited CSVs)

The deposited `backtest_events.csv.txt` contains *summaries* (e.g. `pre_mean`, `pre_sd`) and the event-day `score`, but does not include the full pre/post daily time series windows. Therefore the default, deposit-executable test is a **paired summary test**:

- Define per event $d_i = (\text{score}_i - \mu_{\text{pre},i})$.
- Test statistic: $\bar{d}$.
- Null: signs of $d_i$ are exchangeable (symmetry).
- p-value: **sign-flip permutation** (seeded) with $N=10{,}000$ iterations.

This is implemented in `research/deposit/backtest/backtest_protocol.ipynb`.

#### 6.2 Window-based tests (require additional deposited time series)

If an additional artefact with per-event pre/post daily samples is deposited (recommended for stronger inference), the protocol may use window-based permutation tests on concatenated samples for $\Delta\mu$ and associated effect sizes.

Optional (if SciPy available):

- Wilcoxon signed-rank on paired pre/post means
- Welch t-test for mean shift

### 7) Sensitivity analysis (±10–30% weights)

Sensitivity is computed on the **fixture** (mechanistic sensitivity) and optionally on real snapshots:

- For each connector $k$, perturb weight $w'_k$ by $\pm 10\%$, $\pm 30\%$ one-at-a-time (OAT).
- Recompute L1–L4 on the fixture.
- Output a matrix: rows = (iso2,date), columns = perturbed connector; values = $\Delta \text{NFSI}$ vs baseline.

Artefacts:

- Baseline recompute: `/tmp/nfsi_fixture.csv` (from `recompute_nfsi_fixture.php`)
- Sensitivity output (generated by notebook): `research/deposit/backtest/sensitivity_fixture_delta_matrix.csv.txt`

### 8) Crash-mode evaluation (requires explicit labels)

If a labelled crisis indicator $z_{c,t}$ is deposited (e.g. ACLED-derived crisis days), compute:

- confusion matrix at declared predicate threshold
- Precision / Recall / F1
- ROC/AUC using a continuous severity proxy

If labels are absent, crash-mode evaluation **must be reported as not computable**.

### 9) Reproducibility requirements

- All runs must record:
  - commit hash (implementation constancy)
  - input file hashes (SHA-256)
  - RNG seed used for permutations
  - exact $k$, $W$, date range
