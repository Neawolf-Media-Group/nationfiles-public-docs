\hypertarget{abstract}{%
\subsection{Abstract}\label{abstract}}

This manuscript specifies a \textbf{deterministic, auditable}
computation for the \textbf{NationFiles Stability Index (NFSI)}: a
bounded composite score on \([1,100]\) produced by layers \textbf{L1-L4}
(row normalisation; connector‑day aggregation and smoothing;
country‑level composition with malus/bonus terms; inertia and a
crash‑mode gate). \textbf{Determinism} means: given \textbf{pinned}
upstream connector inputs, \textbf{fixed} release manifests (connector
metadata, optional MI seeds where explicitly declared), and a
\textbf{pinned implementation identifier} (see \textbf{Discussion →
Implementation constancy}), recomputation yields the \textbf{same} NFSI
outputs; the pipeline does \textbf{not} inject stochastic draws outside
documented branches. It states \textbf{definitions, constants,
pseudocode, validation hooks, reproducibility artefacts}, and
\textbf{deposit-backed empirical excerpts} (persistence-baseline
residuals on the toy fixture, named-event classification metrics,
sensitivity magnitudes; aggregated under \textbf{Validation and
Results}) for the NationFiles reference implementation.

\textbf{Keywords:} NationFiles; NFSI; Naciro; OSINT; validation;
stability index; inertia; crash mode; reproducibility.

\hypertarget{introduction}{%
\subsection{Introduction}\label{introduction}}

NationFiles materialises country-level indicators on a fixed cadence
through scheduled \textbf{connectors}. The \textbf{published NFSI}
\(S_c(t)\) for country \(c\) at date \(t\) is \textbf{operationally
defined} by the L1-L4 pipeline--not estimated as a latent factor. On the
scale feeding Layer 4, \textbf{higher NFSI corresponds to lower acute
geopolitical stress}.

\hypertarget{index-mode-published-nfsi-vs-predictive-layer}{%
\subsubsection{Index mode (published NFSI vs Predictive
Layer)}\label{index-mode-published-nfsi-vs-predictive-layer}}

This manuscript normatively specifies the \textbf{daily NFSI composite}
(Layers 1--4): a \textbf{descriptive, auditably deterministic}
country-day score on \([1,100]\) derived from connector inputs and
declared substitution rules. That score functions as the
\textbf{baseline situational index} for NationFiles products and for any
downstream analytics that \textbf{consume} NFSI as a \textbf{state
variable} (level, short-run momentum, cross-country rank).

Where the product surface includes a \textbf{Predictive
Layer}---\textbf{short-horizon outlooks} such as \textbf{24-hour} or
\textbf{7-day} trajectories---those outputs are \textbf{not} produced by
L1--L4 alone. They require a \textbf{separate forecasting stack}
(models, ensembles, recalibration, backtests, and publication semantics)
that may \textbf{condition on} recent NFSI, connector histories, and
other covariates to emit forward-looking estimates with model-specific
uncertainty. In that architecture, \textbf{current NFSI is an input /
anchor signal} to the Predictive Layer, not the forecast itself.

\textbf{Scope boundary (explicit):} This manuscript defines
\textbf{L1--L4 NFSI only}. The \textbf{Predictive Layer} (short-horizon
outlooks such as 24h/7d paths built on top of NFSI) has its \textbf{own}
mathematics, training regime, governance, and acceptance
criteria---\textbf{outside} this document. Persistence baselines and
RMSE scaffolds under \textbf{Validation} are \textbf{non-normative
illustrations} unless superseded by a frozen evaluation annex;
operational forecasts must cite a \textbf{separate} versioned
specification when claimed.

\hypertarget{service-boundaries-nationfiles-vs.-naciro}{%
\subsubsection{Service boundaries (NationFiles
vs.~Naciro)}\label{service-boundaries-nationfiles-vs.-naciro}}

\textbf{NationFiles} is the \textbf{delivery and publication plane}:
public web presence, operator-facing surfaces where applicable, stable
HTTP/API endpoints, and structured \textbf{data exports} (scores,
provenance flags, manifests) consumed by reviewers and downstream
systems. It does \textbf{not} host the full heavy ingestion and scoring
stack as a monolith on the same boundary as static or semi-static site
delivery.

\textbf{Naciro} is a \textbf{separate backend programme}---the
\textbf{processing and intelligence engine}---that runs connector
pipelines, scheduled recomputation, orchestration of raw-to-score
workflows, and any \textbf{model-assisted or NLP preprocessing} required
before Layer‑1 normalisation. Deterministic NFSI layers (L1--L4)
described in this manuscript are implemented and executed in that
\textbf{backend processing} context; outputs are then exposed through
NationFiles as \textbf{published artefacts}.

Readers should assume a \textbf{two-tier layout} (typically \textbf{two
server roles or clusters}): \textbf{(i) frontend / delivery}---TLS
termination, web UI, public API, caching, and export bundles;
\textbf{(ii) backend / engine}---Naciro workers, databases holding
connector and NFSI state, batch jobs, and internal orchestration. Trust
boundaries, scaling, observability, and incident response
\textbf{separate web delivery from compute}: NationFiles answers
\emph{what we publish}; Naciro answers \emph{how scores are produced}
from pinned inputs. Cross-references to ``orchestration'' in
architecture figures denote \textbf{Naciro-side} coordination of
ingestion and scoring, not NationFiles web rendering.

\hypertarget{normative-specification}{%
\subsubsection{Normative specification}\label{normative-specification}}

This manuscript adopts \textbf{one} binding NFSI rule-set:

\begin{itemize}
\tightlist
\item
  \textbf{Security group (\(g=100\)):} multiset \textbf{MIN} over
  connector-day scores; absent structural slots in the MIN construction
  are padded with \textbf{0} (missing-as-worst), \textbf{to strictly
  prevent masking security crises when connectors go missing under
  benign outages or adversarial withholding.}\\
\item
  \textbf{Non-security groups:} anchored average recipe with midpoint
  pads \textbf{50} to uniform length \(M\) (see Layer 2 below).\\
\item
  \textbf{Exports:} operational systems may record padding/imputation
  provenance with boolean flags (\passthrough{\lstinline!was\_padded!},
  \passthrough{\lstinline!was\_imputed!}, \ldots). \textbf{No} parallel
  ``profile × variant'' grid is normative here--alternate numeric
  mappings exist only as \textbf{implementation parity} notes
  (\textbf{Appendix C}).
\end{itemize}

\hypertarget{population-consensus-inputs-to-layer-3}{%
\subsubsection{Population consensus (inputs to Layer
3)}\label{population-consensus-inputs-to-layer-3}}

Population \passthrough{\lstinline!country\_meta.pop!} is a weighted
consensus across public sources (Eurostat, UN WPP, IMF, World Bank, RDF,
CIA, REST Countries, API-Ninjas) with weights \textbf{1.5 / 1.5 / 1.2 /
1.2 / 0.9 / 0.8 / 0.8 / 0.5}. Extrapolation fills gaps;
\passthrough{\lstinline!allowedGrowth = MAX(0.015, masterRate + 0.005)!}
caps implausible positive annual drift from 2024 onward. Details:
\textbf{Appendix A}; deposit mirror \textbf{SM-15} (Supplementary
Material index).

\hypertarget{algebraic-definition}{%
\subsubsection{Algebraic definition}\label{algebraic-definition}}

\textbf{Layer 1 -- Row normalisation.} Let
\(\mathrm{MIN}_{\mathrm{raw}}\), \(\mathrm{MAX}_{\mathrm{raw}}\) be the
extrema of raw values for connector \(k\) on the audit slice;
\(\mathrm{SPAN}=\mathrm{MAX}_{\mathrm{raw}}-\mathrm{MIN}_{\mathrm{raw}}\).
For each row,

\[\mathrm{normalized}=
\begin{cases}
50, & \mathrm{SPAN}\le 0 \text{ or missing bounds} \\
100\cdot\frac{r-\mathrm{MIN}_{\mathrm{raw}}}{\mathrm{SPAN}}, & \text{otherwise}
\end{cases}\]

Let \(\mathrm{norm}_{01}=\mathrm{clamp}(\mathrm{normalized},0,100)\).
With direction flag ``higher raw is worse'',
\(\mathrm{score}_{\mathrm{row}}=\mathrm{round}\!\left(\mathrm{clamp}(100-\mathrm{norm}_{01},0,100),2\right)\);
otherwise swap \(100-\cdot\).

\textbf{Layer 2 -- Connector-day.} Let \(M\) be the maximum row-count
across ISO2 for fixed \((\mathrm{connector\_id},\mathrm{date})\). For
security (\(g=100\)), let observed scores form multiset \(\mathcal{S}\);
pad to length \(M\) with literal \textbf{0} as needed;
\(\mathrm{dayScore}=\min(\mathcal{S}\cup\{\text{padded zeros}\})\). For
non-security groups, build
\(\mathbf{v}=(0,s_1,\ldots,s_k,\underbrace{50,\ldots,50}_{M-k},100)\)
and \(\mathrm{dayScore}=\mathrm{mean}(\mathbf{v})\). Smooth:

\[\mathrm{score}^{L2}_{t}=0.6\cdot \mathrm{dayScore}+0.4\cdot \mathrm{yesterday}\]

(with documented defaults \textbf{70} / \textbf{85} when no yesterday).

\hypertarget{gap-synthesis}{%
\paragraph{Gap synthesis}\label{gap-synthesis}}

Let \(A_D\) denote the deposited availability statistic for calendar day
\(D\) on the audited slice (row-count or coverage tally per frozen
recompute manifest). Define the day-on-day growth ratio

\[\rho_D =
\begin{cases}
A_D / A_{D-1}, & \text{if } A_{D-1} \text{ exists and } A_{D-1} > 0 \\
1, & \text{otherwise}
\end{cases}\]

\textbf{Layer 3 -- Composite.} With
\(\mathrm{effW}_n=g_n\cdot(w_n/100)\cdot u_n\), dummy anchors at \(0\)
and \(100\), weighted mean \(\mathrm{baseScore}\); apply conflict malus
using \(\mathrm{minSec}\) from Layer 3 inputs; fragility / small-pop /
bonus; governance pull via \(\mathrm{est\_total}\) →
\(\mathrm{nfsi\_raw}\) (terms exactly as in \textbf{Appendix A}
constants).

\textbf{Layer 4 -- Security minimum, crash mode, inertia.} Let
\(\mathcal{N}\) denote the connector universe for the release. For each
country-day \((c,t)\), define the set of \textbf{real, non-placeholder}
group-100 connector-day scores as

\[\mathcal{S}_{c,t} = \{ s_{n,c,t} \in [0,100] \mid n \in \mathcal{N},\, g_n = 100,\, \mathrm{isReal}(n,c,t)=1,\, \mathrm{isPlaceholder}(n,c,t)=0 \}.\]

Define

\[\mathrm{minSec}(c,t)=
\begin{cases}
\displaystyle\min_{s\in\mathcal{S}_{c,t}} s, & |\mathcal{S}_{c,t}|>0\\
\texttt{LAYER3\_NO\_SECURITY\_DEFAULT\_MINSEC}, & |\mathcal{S}_{c,t}|=0
\end{cases}\]

\textbf{Crash mode} (normative predicate):

\[\mathrm{crash\_mode}(c,t)=\mathbf{1}\left\{\mathrm{minSec}(c,t)<\texttt{LAYER4\_SECURITY\_CRISIS\_THRESHOLD}\right\}.\]

\textbf{Inertia weight} (normative, binary):

\[w_{\mathrm{inertia}} =
\begin{cases}
0.50, & N_{\mathrm{no\_data}} > 0 \\
0.80, & N_{\mathrm{no\_data}} = 0
\end{cases}\]

If \(\mathrm{crash\_mode}=1\), published NFSI equals Layer‑3 output
(after floor/bounds). Otherwise let \(w=w_{\mathrm{inertia}}\) and apply
inertia and daily cap \(\pm\texttt{LAYER4\_DAILY\_CHANGE\_CAP}\), round
to two decimals.

\hypertarget{normative-sql-mathrmminsec-and-crash-predicate}{%
\subsubsection{\texorpdfstring{Normative SQL -- \(\mathrm{minSec}\) and
crash
predicate}{Normative SQL -- \textbackslash mathrm\{minSec\} and crash predicate}}\label{normative-sql-mathrmminsec-and-crash-predicate}}

The following is \textbf{normative} for audits that materialise scores
in \passthrough{\lstinline!nfsi\_connector!} joined to
\passthrough{\lstinline!datasource\_meta!}. Bind
\passthrough{\lstinline!:default\_minsec!} to
\textbf{\passthrough{\lstinline!LAYER3\_NO\_SECURITY\_DEFAULT\_MINSEC!}}

\begin{lstlisting}
WITH sec AS (
  SELECT nc.score AS score_final
  FROM nfsi_connector nc
  INNER JOIN datasource_meta dm ON dm.connector_id = nc.connector_id
  WHERE nc.iso2 = :iso2
    AND nc.date = :d
    AND dm.nfsi_group = 100
    AND nc.was_placeholder = 0
)
SELECT CASE WHEN COUNT(*) = 0 THEN :default_minsec ELSE MIN(score_final) END AS minSec
FROM sec;
\end{lstlisting}

\textbf{Listing -- Layer 1}

\begin{lstlisting}
SPAN = MAX_RAW - MIN_RAW
FOR each row:
  IF SPAN <= 0 OR bounds missing:
      score_row = 50
  ELSE:
      normalized = 100 * (raw - MIN_RAW) / SPAN
      normalized = CLAMP(normalized, 0, 100)
      IF higher_raw_is_worse: score_row = 100 - normalized ELSE score_row = normalized
  score_row = ROUND(CLAMP(score_row, 0, 100), 2)
\end{lstlisting}

\textbf{Listing -- Layer 2 (normative security MIN + pad 0)}

\begin{lstlisting}
M = MAX row-count k over iso2 for this (connector_id, date)
IF group == 100:
    scores_ext = observed_scores ++ REPEAT(0, M - k_observed)
    dayScore = MIN(scores_ext)
ELSE:
    dayScore = AVG( [0] ++ observed_scores ++ PAD(50, M-k) ++ [100] )
score_final = ROUND(CLAMP(0.6*dayScore + 0.4*yesterday, 0, 100), 2)
\end{lstlisting}

\textbf{Listing -- Layer 4 inertia / crash}

\begin{lstlisting}
minSec = MIN(real group-100 scores) OR DEFAULT_MINSEC
IF minSec < LAYER4_SECURITY_CRISIS_THRESHOLD:
    NFSI_Today = nfsi_raw
ELSE IF prevScore exists:
    inertiaWeight = IF noDataCount > 0 THEN 0.50 ELSE 0.80
    smoothed = prevScore * inertiaWeight + nfsi_raw * (1 - inertiaWeight)
    APPLY daily cap +/- LAYER4_DAILY_CHANGE_CAP vs prevScore
    NFSI_Today = ROUND(smoothed, 2)
\end{lstlisting}

\hypertarget{ethics-and-operational-thresholds}{%
\subsubsection{Ethics and operational
thresholds}\label{ethics-and-operational-thresholds}}

This index can be misused or misinterpreted. Potential harms include:
(i) misclassification leading to inappropriate travel or operational
decisions, (ii) reputational impacts on countries or populations, (iii)
market or policy misuse, and (iv) feedback loops when users treat an
index as ground truth.

Minimum mitigations for deployment and publication: * \textbf{Separation
of concerns:} distinguish descriptive stability scoring from forecasts
and from any policy advice. * \textbf{Human review thresholds (minimum,
audit-ready):} - \textbf{T1 (large movement):} if
\(|\Delta \text{NFSI}_{c,t}| > 6\) within 24h, require human review
before external dissemination. - \textbf{T2 (crash mode):} if crash mode
triggers (\(\min(S)<25\) for group-100 scores excluding placeholders),
require 2-person review within 4h. - \textbf{T3 (data integrity):} if
no-data ratio \(\ge 0.5\), any group-100 connector ingestion anomaly
occurs, or
\passthrough{\lstinline!security\_missingness\_review=required!}
(padding policy / Methodology), require review within 8h. *
\textbf{Transparency:} document score scope, provenance links, and a
dispute channel in published materials. * \textbf{Red-team / misuse
testing:} test for adversarial data gaps, systematic bias from
missingness, and interpretation hazards.

\textbf{Escalation workflow / SLA (minimum):} A deposit-ready SOP is
provided as \textbf{SM-20} (roles A1/A2/E1/M1, evidence requirements,
and a public dispute/correction pathway).

\hypertarget{machine-executable-recompute-recipe}{%
\paragraph{Machine-executable recompute
recipe}\label{machine-executable-recompute-recipe}}

The following is a \textbf{minimal recompute recipe} sufficient to
reproduce Layers 1-4 on a deposited dataset snapshot.

\textbf{Pinned implementation:} a stable implementation identifier
(commit/tag/build provenance) recorded in \textbf{SM-49/SM-50} and
referenced under \textbf{Discussion → Implementation constancy} (single
canonical pin for this manuscript; redacted in the public package to
avoid internal targeting data).

\textbf{Environment (minimum):} * PHP (\textgreater= 8.1) * a SQL
database containing the deposited snapshot tables

\textbf{Input tables (snapshot):} *
\passthrough{\lstinline!connectors\_raw!} -- raw rows for all connectors
(columns at minimum): - \passthrough{\lstinline!connector\_id!} (string)
- \passthrough{\lstinline!iso2!} (string) -
\passthrough{\lstinline!date!} (YYYY-MM-DD) -
\passthrough{\lstinline!raw\_value!} (float) or connector-specific
numeric raw - optional: \passthrough{\lstinline!severity!} (float) if
the connector defines a severity transform before normalisation *
\passthrough{\lstinline!connector\_meta!} -- connector metadata: -
\passthrough{\lstinline!connector\_id!} -
\passthrough{\lstinline!group\_weight!} (e.g.~100/85/60/50/40; negative
= excluded) - \passthrough{\lstinline!weight!} (0-100) -
\passthrough{\lstinline!higher\_raw\_is\_worse!} (bool) -
\passthrough{\lstinline!update\_frequency!} (categorical or numeric
multiplier) * \passthrough{\lstinline!country\_meta!} -- country-level
metadata used by malus/bonus: - \passthrough{\lstinline!iso2!} -
\passthrough{\lstinline!population!} - \(\mathrm{est\_total}\) (0-100
governance) * \passthrough{\lstinline!nfsi\_prev!} -- previous-day NFSI
values (for Layer 4), or empty for cold start.

\textbf{Layer 1 (row score)} * For each
\passthrough{\lstinline!connector\_id!}, compute
\passthrough{\lstinline!min\_raw!}, \passthrough{\lstinline!max\_raw!}
over the snapshot. * For each row: - if \(\mathrm{SPAN}\le 0\) or
missing min/max \(\Rightarrow\) \(\mathrm{score}_{\mathrm{row}} := 50\)
- else
\(\mathrm{normalized}:=100\cdot(\mathrm{raw}-\mathrm{MIN}_{\mathrm{raw}})/\mathrm{SPAN}\)
- if \(\mathrm{higher\_raw\_is\_worse}=1\) \(\Rightarrow\)
\(\mathrm{score}_{\mathrm{row}} := 100-\mathrm{normalized}\), else
\(\mathrm{score}_{\mathrm{row}} := \mathrm{normalized}\) - clamp to
{[}0,100{]}, round to 2 decimals.

\textbf{Layer 2 (connector-day score)} * Collect all
\(\mathrm{score}_{\mathrm{row}}\) for a given
\((\mathrm{connector\_id},\mathrm{iso2},\mathrm{date})\). * If
\(g=100\): \(\mathrm{dayScore}=\min(\mathcal{S})\) after padding absent
multiset slots with \textbf{0} (manuscript-normative missing-as-worst).
* Else: compute \(\mathrm{dayScore}\) by the anchored-average
construction with midpoint pads \textbf{50} (see \textbf{Layer 2}
above). * Smooth with previous day:
\(\mathrm{score}_{\mathrm{final}}=0.6\,\mathrm{dayScore}+0.4\,\mathrm{yesterday}\),
where \(\mathrm{yesterday}\) defaults to 70 (security) or 85 (others)
when absent.

\textbf{Layer 3 (country score)} * For each
\((\mathrm{iso2},\mathrm{date})\) aggregate all connector-day
\(\mathrm{score}_{\mathrm{final}}\) into a weighted mean using: -
\(\mathrm{effW}_n=g_n\cdot(w_n/100)\cdot u_n\) - include dummies 0 and
100 with weight 1 each * Apply malus/bonus sequence exactly as in Layer
3 / Appendix B.

\textbf{Layer 4 (inertia and crash mode)} * Compute crash mode as
specified for Layer 4: min of real, non-placeholder group-100 scores
\textless{} 25 → bypass smoothing. * Else apply inertia and daily-change
cap ±3.

\hypertarget{hypotheses-and-baselines}{%
\subsubsection{Hypotheses and
baselines}\label{hypotheses-and-baselines}}

\begin{itemize}
\tightlist
\item
  \textbf{H1 (event reaction):} event-window shift differs from baseline
  windows.\\
\item
  \textbf{H2 (classification quality):} crash predicate and event labels
  achieve better-than-random discrimination.\\
\item
  \textbf{H3 (forecast baseline):} persistence baseline is reported and
  compared to alternative baselines.
\end{itemize}

Baselines to include in deposited evaluations:

\begin{itemize}
\item
  persistence: \((\hat{y}_{t+h} = y_t)\) (naive copy-value forecast),
\item
  \textbf{GDELT-derived alarm score baseline (reproducible):} For each
  country-day \((c,t)\), compute the \textbf{day-mean Goldstein scale}
  \(G_{c,t}\) over all GDELT event rows retained by the \textbf{same
  iso2/day filter} recorded in the deposit's GDELT→Layer‑1 recipe
  (\passthrough{\lstinline!CountriesGdeltGlobRadarConnector!} row
  window; empty days treated as missing unless a declared forward-fill
  rule is versioned in the evaluation manifest). Map to an alarm level
  on \([0,100]\) via \(a_{c,t} = 100 \cdot \frac{10 - G_{c,t}}{20}\), so
  that \(G=-10 \Rightarrow a=100\) (most conflictual) and
  \(G=+10 \Rightarrow a=0\). The series \(\{a_{c,t}\}\) is the
  \textbf{GDELT alarm baseline} for windowed contrasts against NFSI (and
  may be \(z\)-scored in the evaluation script, provided the transform
  is deposited).
\item
  externally published index baseline where license permits comparison.
\end{itemize}

\hypertarget{epistemic-scope}{%
\subsubsection{Epistemic scope}\label{epistemic-scope}}

\begin{itemize}
\tightlist
\item
  \textbf{Not causal identification.} The pipeline specifies a
  deterministic mapping from declared inputs to \(S_c(t)\); it does
  \textbf{not}, by itself, identify causal effects of policies,
  incidents, or interventions on countries' stability outcomes.
\item
  \textbf{Composite subjectivity.} Connector weights, group assignments,
  malus/bonus terms, and inertia/crash thresholds encode
  \textbf{engineering and policy choices}. They are documented and
  sweepable (\textbf{Validation and Results → Sensitivity and
  robustness}) but not uniquely determined by a single welfare
  objective.
\item
  \textbf{Uncertainty.} Published NFSI values are \textbf{point
  outputs}. Probabilistic bands are \textbf{not} implied except where
  \textbf{Variant D} multiple imputation documents seeds and manifests;
  other layers are deterministic given pinned inputs.
\end{itemize}

\hypertarget{endogeneity-and-feedback}{%
\subsubsection{Endogeneity and
feedback}\label{endogeneity-and-feedback}}

High-frequency inputs (e.g.~news-derived risk feeds) may co-move with
geopolitical stress. \textbf{Misinterpretation risk:} treating NFSI as
an independent ``ground truth'' can confuse descriptive composite
movement with causal attribution. Operators SHOULD separate
\textbf{inputs}, \textbf{outputs}, and \textbf{downstream decisions}
(see \textbf{Governance ethics subsection}).

\hypertarget{threat-model}{%
\paragraph{Threat model}\label{threat-model}}

This subsection is \textbf{normative} for publication‑grade security
review of an operational, connector‑backed stability index and documents
minimum threat assumptions and mitigations.

\textbf{Assets and trust boundaries} * \textbf{Assets:} raw connector
payloads; Layer‑1/2 intermediates; published NFSI values;
provenance/flags (padded/imputed/placeholder); release manifests; audit
logs. * \textbf{Boundaries:} connector ingestion boundary (external →
internal); computation boundary (L1-L4); publication boundary (API/web
exports).

\textbf{Threats / attack vectors} * \textbf{Data poisoning:} adversary
injects or manipulates upstream signals (e.g.~automated news spam,
event-source manipulation) to move security-group minima or amplify
deltas. * \textbf{Adversarial missingness:} targeted outages/delays of
high-influence connectors to suppress crash mode or to bias the
composite toward neutral substitutions. * \textbf{Weight/constant
tampering:} unauthorized changes to \textbf{SM-15} / connector metadata
(weights, groups, update multipliers) to alter scores. * \textbf{Replay
/ stale-data attacks:} old connector-day scores replayed to avoid
detection of acute changes. * \textbf{Export integrity attacks:}
tampering with published JSON/CSV so consumers see altered NFSI values
or missing provenance flags.

\textbf{Mitigations (minimum required)} * \textbf{Provenance +
flagging:} exports MUST include
\passthrough{\lstinline!was\_placeholder!},
\passthrough{\lstinline!was\_padded!},
\passthrough{\lstinline!was\_imputed!}, coverage metrics, and
last-update timestamps per connector-day (optional legacy keys such as
\passthrough{\lstinline!pad\_variant!} may remain for
backward-compatible audits--see \textbf{Appendix C}). *
\textbf{Integrity gates:} deterministic recompute fixtures, invariant
checks, and evidence hashes (see \textbf{Reproducibility} subsection and
\textbf{SM-48}). * \textbf{Change control:} constants/weights changes
require logged approvals and tagged releases (see \textbf{SM-19}). *
\textbf{Anti-replay:} ingestion stores provider snapshot timestamps and
rejects/flags out-of-window payloads (operator policy; export the
resulting flags). * \textbf{Monitoring:} operational alerting on
coverage drops, latency spikes, and abrupt cross-connector distribution
shifts. For \textbf{country-day} \(\mathrm{noDataRatio}\)
(\textbf{Methodology / Appendix B}): emit a \textbf{severity‑2
(warning)} when \(\mathrm{noDataRatio} \geq 0.40\) on monitored
aggregates; escalate to \textbf{severity‑1} when
\(\mathrm{noDataRatio} \geq 0.50\). These thresholds track
\textbf{missingness operational risk}; Layer‑4 inertia remains
\textbf{binary} (\(0.50\) if \(N_{\mathrm{no\_data}}>0\), else \(0.80\);
\textbf{Methodology / Appendix A}). * \textbf{Red-team tests:}
adversarial missingness simulations (random/block/country-targeted) must
be run per release candidate; publish FPR/FNR for crash gate where
labels exist.

\textbf{Discrimination limits: random outage vs systematic suppression
(Layers 1-2).} Layer‑1/Layer‑2 score algebra \textbf{cannot}, by itself,
invert the missingness mechanism: a benign CDN outage, a routing
partition, and a coordinated state-level signal blackout can yield
\textbf{indistinguishable} sparse score matrices at the connector-day
granularity. The NFSI pipeline therefore does \textbf{not} claim to
classify ``server fault'' vs ``strategic withholding'' from scores
alone. Instead, audit-grade operation must fuse \textbf{orthogonal
evidence}: (i) cross-connector correlation of dropout (single-AS
failures vs broad, geography-aligned gaps); (ii) external reachability /
BGP / public incident telemetry where available; (iii) temporal
clustering relative to known conflict escalations; (iv) mandatory
\passthrough{\lstinline!security\_missingness\_review!} when structural
pads contribute to security MIN under the \textbf{manuscript normative}
missing-as-worst rule (\textbf{Methodology}). Neutral midpoint pads
(\textbf{50}) apply \textbf{only} to non-security anchored averages--not
to security MIN semantics.

\hypertarget{ethics-and-societal-impact}{%
\paragraph{Ethics and societal
impact}\label{ethics-and-societal-impact}}

Beyond operational threat controls (\textbf{Governance subsection
above}) and protocol ethics (\textbf{Validation (T1-T3)}),
publication-grade use SHOULD address:

\begin{itemize}
\tightlist
\item
  \textbf{Misuse / dual-use:} Composite indices can inform travel,
  finance, insurance, or migration narratives. Publishers SHOULD avoid
  implying precision beyond documented uncertainty (see
  \textbf{Limitations}) and SHOULD maintain dispute and correction
  pathways (\textbf{SM-20}).
\item
  \textbf{Equity and dignity:} Country-level scores aggregate
  heterogeneous populations; they MUST NOT substitute for situational
  intelligence or ground verification in humanitarian or security
  contexts.
\item
  \textbf{Feedback loops:} Repeated consumption of the same headline
  score in automated systems may amplify volatility perception;
  governance SHOULD favour provenance-rich exports and human gates
  (\textbf{T1-T3}).
\item
  \textbf{Environmental footprint:} High-frequency ingestion has compute
  and energy costs; operators SHOULD document retention and batching
  policies (\textbf{SM-22}).
\end{itemize}

\textbf{NFSI} & NationFiles Stability Index. A 0-100 normalised
stability indicator per country and day. Higher value = more stable
assessment; computed from multiple data sources across four processing
layers (Layers 1-4). \\
\textbf{Layer 1} & First processing layer: raw values from each source
are normalised to a row-level score 0-100 (min-max, with fixed direction
`higher = better/worse'). \\
\textbf{Layer 2} & Second layer: row scores are aggregated per source,
country, and date into a daily score and smoothed with the previous day
(e.g.~60\% today, 40\% previous day). \\
\textbf{Layer 3} & Third layer: the country NFSI (raw score) is computed
from all source scores: weighted average with effective weights,
conflict malus, WGI pull, and other adjustments. \\
\textbf{Layer 4} & Fourth layer: daily smoothing (inertia). The shipped
implementation applies \(w_{\mathrm{inertia}}\) to \textbf{yesterday's
published NFSI} and \((1-w_{\mathrm{inertia}})\) to \textbf{today's
Layer‑3 bounded score}
\(\max(\texttt{LAYER3\_SCORE\_FLOOR},\mathrm{nfsi\_raw}^{\mathrm{rounded}})\)

\textbf{Effective} weights are
\textbf{\((w_{\mathrm{prev}},w_{\mathrm{today}})=(0.50,0.50)\)} when any
neutral Layer‑3 substitution occurred (\(N_{\mathrm{no\_data}}>0\)),
else \textbf{\((0.80,0.20)\)}; see \textbf{Methodology / Appendix A}.
Crash mode bypasses smoothing;
\(\pm\texttt{LAYER4\_DAILY\_CHANGE\_CAP}\) applies when inertia runs. \\
\textbf{Raw value (raw)} & Original numeric value from a data source
before conversion to a 0-100 score (e.g.~conflict count, percentage,
scale value). \\
\textbf{Normalisation} & Conversion of raw values into a common range
(here 0-100). With min-max: (value - minimum) / (maximum - minimum) *
100, optionally inverted when `higher = worse'. \\
\textbf{Score (row / daily / country)} & A value bounded to 0-100: row
score per record (Layer 1), daily score per source/country/date (Layer
2), country score = NFSI (Layers 3-4). \\
\textbf{Goldstein scale} & Scale used by GDELT from -10 (highly
conflictual) to +10 (cooperative). Translated into stability scores in
NFSI logic (higher Goldstein = better stability). \\
\textbf{Dummy value} & Fixed additive value (0 and 100) in aggregation
so that averages and weighting remain stable even when few sources are
available. \\
\textbf{Inertia} & Smoothing over time: published NFSI blends
yesterday's value with today's Layer‑3 output. \textbf{Shipped} policy:
faster reaction (\(0.50\) previous weight) whenever \textbf{any} neutral
Layer‑3 substitution exists; otherwise standard \textbf{\(0.80\)}
(\textbf{Methodology / Appendix A}). \\
\textbf{Recovery} & When no new data exists for a country/date, the
score is gradually raised (up to cap 95) so that gaps are not penalised
indefinitely. \\
\textbf{Recovery cap} & Upper bound on recovery-driven score increases
without new measurements
(e.g.~\passthrough{\lstinline!LAYER2\_RECOVERY\_CAP=95!}). Bounded
recovery mechanisms prevent asymptotic convergence to an unrealistically
``perfect'' stability score when observations remain absent. \\
\textbf{Conflict malus} & Deduction from the NFSI when the minimum of
security indicators (e.g.~conflicts, violence) falls below a threshold
(70). Emphasises the role of security data. \\
\textbf{WGI (Worldwide Governance Indicators)} & World Bank indicators
of government quality (rule of law, effectiveness, etc.). In NFSI: `WGI
pull' can raise the raw score when governance is strong. \\
\textbf{Security group (group 100)} & Thematic group of
security-critical sources (e.g.~conflicts, travel warnings). For daily
aggregation the minimum is taken (one critical event suffices). \\
\textbf{Coverage} & For a fixed
\passthrough{\lstinline!(connector\_id, date)!}, the fraction of ISO2
countries with at least one \textbf{real Layer‑1} row
(\passthrough{\lstinline!k\_meas>0!}). Used to flag low-coverage
connector-days. \\
\textbf{Trend synthesis} & Deterministic imputation step used when a
connector-day is active for some countries but missing for a specific
country; the missing cell is synthesised from last known value and
cross-country day trend and must be flagged as imputed/placeholder as
applicable. \\
\textbf{Connector / data source} & An integrated data source (e.g.~World
Bank, GDELT, ACLED) that contributes to the NFSI in Layers 1-3. Each
connector has a thematic group and a weight. \\
\textbf{\passthrough{\lstinline!contributors\_count!}} & In

neutral fills). Distinct from ``rows with measured Layer‑1
evidence.'' \\
\textbf{No-data (Layer‑3 substitution)} & A connector lacks a real
\passthrough{\lstinline!nfsi\_connector!} observation for
\passthrough{\lstinline!(iso2, date)!} during Layer‑3 aggregation.
Implemented as
\textbf{\passthrough{\lstinline!LAYER3\_NO\_DATA\_NEUTRAL\_SCORE!} (50)}

neutral substitution is \textbf{never} mistaken for measured security
deterioration. \\

explicitly. \\

\hypertarget{conclusion}{%
\subsection{Conclusion}\label{conclusion}}

The NationFiles Stability Index is specified as a \textbf{deterministic}
mapping from declared connector inputs and manifests to a bounded daily
country score \(S_c(t)\in[1,100]\). Four layers--normalisation,
connector-day aggregation with explicit missingness semantics, a
weighted national composite with malus/bonus terms, and inertia with a
crash-mode gate driven by measured security minima--yield reproducible
outputs under a pinned implementation. \textbf{Validation and Results}
summarises deposit-backed metrics (fixture persistence errors,
named-event discrimination, sensitivity panels, structural comparison to
annual indices). Full rank correlations against FSI/GPI/WGI require
frozen merge manifests. Operators SHOULD combine headline scores with
provenance exports, mandatory human gates where stated, and the
reproducibility bundle described under \textbf{Discussion}.

\hypertarget{appendix-b-layer-pseudocode}{%
\subsection{Appendix B -- Layer
pseudocode}\label{appendix-b-layer-pseudocode}}

The authoritative full pseudocode is \textbf{SM-28}. The deposit text
may still describe \textbf{100}-based security MIN padding for recompute
bundle compatibility; the \textbf{manuscript-normative} security MIN
uses structural pad \textbf{0} (\textbf{Methodology}). Excerpt
(opening):

\begin{lstlisting}
NFSI L1-L4 deterministic pseudocode

========================
L1 - Row-level normalisation
========================
INPUT per connector k:
  - rows r_i with raw_value r_i and row timestamp/event id (for deterministic sorting)
  - direction higher_raw_is_worse_k in {0,1}
  - bounds min_raw_k, max_raw_k over the deposited snapshot for connector k

FOR each row i:
  span = max_raw_k - min_raw_k
  IF span <= 0 OR min_raw_k/max_raw_k missing:
      normalized = 50
  ELSE:
      normalized = 100 * (r_i - min_raw_k) / span
  normalized = clamp(normalized, 0, 100)

  IF higher_raw_is_worse_k == 1:
      score_row = 100 - normalized
  ELSE:
      score_row = normalized
  score_row = round2(clamp(score_row, 0, 100))

OUTPUT:
  - score_row per row (0..100)

========================
L2 - Connector-day aggregation + smoothing + recovery
========================
INPUT per (connector k, country c, day t):
  - all L1 score_row values for that triple, sorted deterministically by event_timestamp ASC
  - group_weight g_k (100 = security group)
  - pad policy:
      - security: MIN(scores), missing padded with 100 for MIN semantics
      - non-security: arr = [0] + scores + [100]; dayScore = AVG(arr)
  - smoothing weights alpha=0.6 (today), beta=0.4 (yesterday)
  - default yesterday:
      - security: 70
      - other: 85
  - recovery:
      - per day without data: +0.2 (security) or +1.0 (other), capped at 95
      - maximum recovery days: 90

DAY AGGREGATION:
  IF g_k == 100:
      dayScore = MIN(scores)  (if score list empty: dayScore is "missing")
  ELSE:
      arr = [0] + scores + [100]
      dayScore = AVG(arr)

SMOOTHING (if dayScore present):
  y = yesterday L2 score for (k,c,t-1) if exists else default_yesterday(g_k)
  score_final = alpha * dayScore + beta * y
  score_final = round2(clamp(score_final, 0, 100))

RECOVERY (if dayScore missing for a day):
  Start from last available score_final on previous day; apply per-day recovery step until:
    - next real dayScore exists, OR
    - recovery reaches cap 95, OR
    - 90 days filled.

OUTPUT:
  - score_final per connector/country/day (0..100)

========================
L3 - Country composition (nfsi_raw)
========================
INPUT per (country c, day t):
  - per connector k: L2 score_final (0..100) if present else missing
  - connector meta:
      - group g_k (int; group < 0 excluded)
      - scoreValue_k = connector_weight_k / 100 (float 0..1)
      - updateMult_k (float)
  - constants:
      - LAYER3_NO_DATA_NEUTRAL_SCORE = 50
      - conflict threshold = 70, factor=1.0, cap=35
      - population ref = 45,000,000; pop log min=100,000; popNeg cap=2.0
      - fragility factor=3.0 cap=15; WGI_0_10 = est_total/10; governanceGap=10-WGI_0_10
      - small country threshold=5,000,000; malus per log10=4.0 cap=25
      - population bonus = min(4, log10(pop)*0.5)
      - WGI pull = 0.95
      - floor=1 cap=100
\end{lstlisting}
